# Factory backlog

Things to do later: ideas, fixes and follow-ups that came up and aren't anyone's
current work. Anyone adds to it at any time; the factory commands add to it too (see
`README.md`, *Backlog*).

- **One line per item**: what's wrong or wanted — why it matters *(from: where it came
  up, date)*.
- **In progress**: `/spec` appends `→ <App> NNN` to the line it starts from.
- **Done**: `/release` removes the line. A dropped idea is deleted, with the reason in the
  commit message.
- This is a memory aid, not a tracker. Planning happens in the work record.

(The original backlog is private: it holds notes about one specific server setup.
This repo starts with an empty one.)
